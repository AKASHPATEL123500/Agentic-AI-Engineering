# Security

## Reporting a Security Issue

If you discover a security vulnerability in this repository, please report it privately and responsibly.

1. Do not create a public issue for security vulnerabilities.
2. Contact the repository owner directly with details.
3. Include a clear description, affected files, and steps to reproduce.

## What to Include

- Affected version or commit
- Description of the issue
- Proof of concept or reproduction steps
- Any relevant logs or screenshots

## Responsible Disclosure

Please allow a reasonable time for the maintainers to respond and fix the issue before publicly disclosing it.

## Public Dependencies

This repository uses third-party dependencies. Keep dependencies up to date and review security advisories before upgrading.
