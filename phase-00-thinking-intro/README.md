## What is Ai Agent

Ai agent is a system. it works like this, And it is also called as Autonomous AI

```bash
- A ai agent can think
- A ai agent can work
- A ai agent can use tool when it need
- A ai agent can make plan and decison
- A ai agent can work with loop
- And a ai agent can use tool and take some action
```

#### In simple word. working flow

```bash
- Goal ( Agentic ai ka ek goal hota hai)
- think
- descion
- plaing
- Action
- resutl
```

#### Example

```bash
User bolta hai mujhe note.txt file read karna hai.
Agent work
- Goal mila Read file ka
- Think kiya file kaah per hai
- Then it use a Tool to read-file ( Action )
- File mila
- Then return final answer
```
