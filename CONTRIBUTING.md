# Contributing

Thank you for your interest in contributing to this project! Follow these guidelines to make the contribution process smooth and efficient.

## How to Contribute

1. Fork the repository or clone the main repository.
2. Create a new branch for your change:
   ```bash
   git checkout -b feature/your-feature-name
   ```

```
3. Make your changes in a clear and focused way.
4. Run any available tests and ensure your changes work.
5. Open a pull request with a concise description of what changed and why.

## Contribution Types

- Bug fixes
- Documentation improvements
- New examples or tools
- Refactorings for clarity and maintainability

## Code Style

- Prefer clear and simple code.
- Use consistent naming and formatting.
- Add comments for non-obvious logic.

## Tests

If the repository includes tests, please run them before submitting changes.

## Pull Request Checklist

- [ ] Code changes are related to the issue or improvement.
- [ ] No unrelated changes are included.
- [ ] The code is readable and maintainable.
- [ ] Documentation is updated if needed.
- [ ] All tests pass.
```
