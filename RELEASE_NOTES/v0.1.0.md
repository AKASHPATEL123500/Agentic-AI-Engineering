# Release v0.1.0 — Agentic AI Engineering (Draft)

Release date: 2026-08-13

Summary

- Initial public draft release for the Agentic AI Engineering repository.
- Focus: foundational tooling for a modular agent execution platform (registry, discovery, loader, dispatcher).

Highlights

- Documentation: Detailed `README.md` files added for `06-tool-registry`, `07-tool-discovery`, and `08-tool-loading-system` modules.
- Governance: Added and standardized repository governance files: `LICENSE` (MIT), `SECURITY.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `CHANGELOG.md`, and `.gitattributes`.
- Collaboration: Added GitHub templates for issues and pull requests under `.github/ISSUE_TEMPLATE` and `PULL_REQUEST_TEMPLATE.md`.
- Stability fixes: Adjusted runtime paths (absolute paths for tool auth/session storage) and improved logging in the WhatsApp example tool.

Notable files changed/added

- `src/01-registry-and-execution/06-tool-registry/README.md` — registry design and usage.
- `src/01-registry-and-execution/07-tool-discovery/README.md` — discovery patterns and examples.
- `src/01-registry-and-execution/08-tool-loading-system/README.md` — loader architecture and lifecycle.
- `LICENSE` — replaced with MIT license.
- `.github/ISSUE_TEMPLATE/bug_report.md`
- `.github/ISSUE_TEMPLATE/feature_request.md`
- `.github/PULL_REQUEST_TEMPLATE.md`
- `RELEASE_NOTES/v0.1.0.md` (this file)

Breaking changes

- None expected in this draft release. Most changes are documentation, repo metadata, and non-breaking loader/registry adjustments.

Upgrade / Quickstart

1. Clone the repo and install dependencies (if using Node):

```bash
npm install
# or
bun install
```

2. Run a recommended example or tests (example paths may vary):

```bash
npx tsx src/01-registry-and-execution/09-tool-dispatcher/run.ts
# or run the module tests if present
bun test
```
