### Tools

Production me Tool ko ek Worker ki tarah dekhte hain.

### Tools ke pass kya kya hona chiye

```bash
- Name
- Description
- Input
- Output
- Execute
```

`Ek tool ke pass intni info honi chiye`

##### Explaintions

```bash
1. Name: read-file-tool (ek tool ka naam hona chiye taki agent ko pata chle ki kya karta hai ye tool)
2. Description : Reads a file from disk and returns its content. ( isse agent ko pata chlat hai ki kya ye kaam karta hai)
3. Input: kya input leta hai
4. Output: kya output and kise deta hai
5. Execuet: tool actual kaam kise karega
```
